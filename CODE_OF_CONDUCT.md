# Code of Conduct

## Our pledge

We want this project's issues, pull requests, and discussions to be a
welcoming, harassment-free space for everyone, regardless of experience
level, background, or identity.

## Expected behavior

- Be respectful and considerate in comments, reviews, and issue reports.
- Assume good faith. Disagree with ideas, not people.
- Give and accept constructive feedback gracefully.
- Focus criticism on the code and the reasoning behind it.

## Unacceptable behavior

- Harassment, insults, or personal attacks, public or private.
- Discriminatory jokes, language, or imagery.
- Publishing others' private information without consent.
- Sustained disruption of discussions, issues, or reviews.

## Scope

This applies within all project spaces (issues, pull requests, discussions,
commit messages) and in any other setting when someone is representing the
project.

## Enforcement

If you experience or witness unacceptable behavior, open a GitHub issue
tagged `conduct`, or contact the maintainer directly through their GitHub
profile if the report shouldn't be public. Reports will be reviewed and
addressed as quickly as possible. Maintainers may remove comments, close
threads, or block contributors who violate this code of conduct.
