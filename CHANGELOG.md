# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
This project doesn't yet use version tags, so changes are listed under
[Unreleased] until a first release is cut.

## [Unreleased]

### Added

- Interactive news feed demo (`index.html`) covering fan-out-on-write vs.
  fan-out-on-read, a bounded message queue with backpressure, follower
  sharding, and a per-account rate limiter, modeled on the System Design
  Primer's news feed design.
- `README.md` describing the demo and how to run it locally.
- MIT `LICENSE`.
- `CONTRIBUTING.md` covering the project's single-file/no-build-step shape,
  manual verification steps, and code style.
- `CODE_OF_CONDUCT.md`.
- Bug report and feature/scenario-idea issue templates under
  `.github/ISSUE_TEMPLATE/`.
- Pull request template at `.github/PULL_REQUEST_TEMPLATE.md`.
- `CHANGELOG.md` (this file).
